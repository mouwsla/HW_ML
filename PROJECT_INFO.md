# Информация о проекте HW_ML

## Краткое описание

`HW_ML` — учебный проект по машинному обучению на Python с использованием PyTorch. В проекте собраны несколько домашних заданий: базовые операции с тензорами, обучение простых нейросетей, загрузка датасета CIFAR-10 и обучение сверточной модели для классификации изображений.

## Структура проекта

| Файл | Описание |
| --- | --- |
| `hw1.py` | Демонстрация операций с тензорами PyTorch и пример нейросети для приближенного умножения двух чисел. Обучение модели закомментировано, готовые веса загружаются из `multiplication_model.pth`. |
| `hw2.py` | Бинарный классификатор на синтетических данных. Сравнивается обучение с оптимизаторами Adam и SGD, результат отображается на графике loss. |
| `hw3.py` | Загрузка и подготовка датасета CIFAR-10 через `torchvision.datasets.CIFAR10` и `DataLoader`. |
| `hw4.py` | Сверточная нейросеть для классификации изображений CIFAR-10. Скрипт обучает модель, сохраняет лучшие веса в `LearnModel.pth`, затем проверяет модель на тестовых изображениях. |
| `multiplication_model.pth` | Сохраненные веса модели из `hw1.py` для задачи умножения двух чисел. |
| `LearnModel.pth` | Сохраненные веса модели классификации изображений из `hw4.py`. |

## Основные технологии

- Python
- PyTorch
- Torchvision
- NumPy
- Matplotlib

## Как запустить

Перед запуском нужно установить зависимости:

```bash
pip install torch torchvision numpy matplotlib
```

Запуск отдельных заданий:

```bash
python hw1.py
python hw2.py
python hw3.py
python hw4.py
```

## Данные и модели

- `hw3.py` и `hw4.py` автоматически скачивают CIFAR-10 в папку `Data_10`.
- `hw1.py` использует файл `multiplication_model.pth` для загрузки уже обученной модели.
- `hw4.py` сохраняет лучшую модель в `LearnModel.pth` во время обучения.

## Что делает каждый скрипт

### `hw1.py`

1. Создает два случайных тензора размером `3x3`.
2. Выполняет сложение, поэлементное умножение и транспонирование.
3. Считает средние и максимальные значения.
4. Загружает нейросеть `MultModule` из сохраненных весов.
5. Проверяет модель на нескольких парах чисел.

### `hw2.py`

1. Генерирует синтетический датасет из 1000 объектов с 5 признаками.
2. Создает бинарные метки по правилу: сумма признаков больше нуля.
3. Обучает одну и ту же модель с Adam и SGD.
4. Строит график сравнения loss для двух оптимизаторов.

### `hw3.py`

1. Настраивает преобразования изображений CIFAR-10.
2. Загружает train и test части датасета.
3. Создает `DataLoader` для батчевой обработки данных.

### `hw4.py`

1. Загружает CIFAR-10.
2. Описывает CNN-модель `NewImgModel`.
3. Обучает модель 10 эпох.
4. Сохраняет веса с лучшей точностью.
5. Загружает сохраненную модель и показывает предсказания на тестовых изображениях.

## Примечания

- При первом запуске `hw3.py` или `hw4.py` потребуется интернет для скачивания CIFAR-10.
- `hw2.py` и `hw4.py` открывают окна с графиками через Matplotlib.
- В проекте пока нет отдельного файла `requirements.txt`, поэтому зависимости перечислены в этом документе.
